## Already aligned — preserve these decisions

- Weft uses the same ordinary stdio interface as agents. No Weft opcode set, VM,
  recipe endpoint, direct database writer or second effect engine.
- Weft owns language, semantic analysis, finite evaluation and explanations.
  Writfold owns knowledge identity, admission, context-specific assessment,
  retained closure and authorization. Neither a model witness nor a successful
  local proof creates effect authority.
- References preserve realm/kind/revision/profile distinctions. Short handles
  are not durable references or grants. Citation-table generation, request
  generation and session incarnation are different counters.
- Native Git blob identity, raw whole-capture SHA-256 and selected-byte SHA-256
  remain separate. Writfold's core observation-content identity is the raw capture
  digest, not the Git object ID. A `wf1:blob` fingerprint is another domain again.
- A portable Weft proof/model-node reference needs the exact report/model artifact
  identity and schema plus the local node ID. Source-file SHA-256 alone does not
  identify an arbitrary report or model produced from that source.
- Resolution, correspondence, assessment, interpretation and inference remain
  separate. Support dimensions must not be coerced into classical truth without
  a qualified interpretation/bridge profile. Hypotheses remain explicit.

## Transport and artifact boundary

The planned ordinary transport is bounded JSON-RPC 2.0 over stdio, one JSON object
per line, with initialization protocol version exactly the string `"2"`. It is
LSP-like architecturally, not a claim of implementing LSP methods or adopting
`Content-Length` framing. Final method/response schemas must come from Writfold's
landed and qualified contract.

The Writfold frame ceiling is 65,536 bytes. Weft's current report budget is
16,777,216 bytes. Reports, models, source captures and read closures therefore need
the planned ordinary bounded artifact/selection-transfer mechanism when larger
than a frame. Bind the transfer to exact identity, length, order, scope, integrity
and completeness. Do not increase the frame ceiling, send an entire oversized
report as one request, silently truncate it, or reinterpret an expired transfer.
