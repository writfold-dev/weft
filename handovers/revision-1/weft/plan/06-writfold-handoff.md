## Requested capability contracts

Expose the same protocol-2 interface used by agents. Initialize negotiates only
implemented capabilities. Bind instance/incarnation/request generation and reject
stale replies, malformed/oversized frames and unsupported methods. Resolve an
explicit authorized realm/context/release and intended use; never choose ambient
latest context. Return typed refusal and exact stable bindings. Supply the actual
versioned method/response contracts for Weft to consume, rather than Weft inventing
them. Current transport ceiling is 65,536 bytes; larger retained artifacts need
an explicitly qualified transfer/selection mechanism, not oversized frames.

### WR2 — exact durable citation resolution

Consume current public citation syntax. Return full citation/release/context plus
realm/repository/revision/path/content/representation/profile and selector units.
Return exact retained bytes or explicit denied/unavailable/invalid/unsupported
outcomes; no current-working-tree fallback. Preserve historical signed/public
bytes. Reuse CIT01 and production V22 obligations; equal bytes and legacy normalized
span checksums do not prove identity or semantic succession.

### WR3 — compact handles and qualified external references

citation-table generation from protocol request generation/incarnation. Same
numeric ID in another realm/session cannot collide semantically. A global locator
must preserve existing type/namespace/realm/revision distinctions; do not replace
historical IDs with a new universal UUID or treat a locator as a capability.

### WR4 — assessment and interpretation inputs

For exact claim/asset/rule bindings, return existing context-specific support,
applicability, freshness, validation, contestation, availability and usability

Keep resolution, correspondence and assessment separate. New solver-theory bridge

### WR5 — frozen read closure and shared contract distribution
